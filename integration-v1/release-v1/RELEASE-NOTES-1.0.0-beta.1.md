# 小睦 Codex 1.0.0-beta.1 发布说明

更新日期：2026-10-31。候选编号：`20261031-3384-rc1`。状态：本地 Beta RC，供受邀测试，未公开发布。

这是非官方粉丝外观皮肤。当前支持并实机验证的客户端为 **Microsoft Store Codex 26.1027.3384.0**；其他版本需要重新检测和验收。客户端归档内 `package.json` 标注的 `26.1027.30824` 不替代 Store 版本。Node.js 要求为 22 或更高版本，固定路径 `C:\Program Files\nodejs`；使用皮肤前需选择 Codex 原生浅色主题。

对外标识为 `1.0.0-beta.1`；本候选保留运行清单版本和安装目录版本 `1.0.0`，兼容现有安装器。管理界面显示 `1.0.0` 属于预期行为，请同时核对候选编号。

- 适配 Store `26.1027.3384.0` 的组件位置变化与聊天右键菜单，在身份和组件校验通过后启用相应装饰。

- 更新使用说明，明确版本范围、浅色主题与 Node.js 路径要求，以及来源、素材和分发说明。

## 安装、更新与回退

首次安装请按 [USAGE.md](USAGE.md) 操作，从完整解压包的 `skin\manage.vbs` 打开。保留完整包作为修复来源。

本候选没有自动升级功能：完整的既有 `1.0.0` 安装重复点击“安装 / 修复”只补齐入口。更新前先暂停皮肤并关闭管理窗口，在新完整包的 `skin` 文件夹中打开 Windows PowerShell，然后执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -SourceRoot . -Repair
```

旧目录保存至 `backup-repair-*`，入口记录保留，更新后保持暂停；确认重新检测通过后再主动启用。详细步骤和回退方法见 [USAGE.md](USAGE.md)。组织强制策略阻止时停止并记录，不修改全局执行策略。

需要撤销外观时使用“暂停皮肤”或“恢复官方外观”，Codex 保持打开。恢复会保留专用小睦/管理入口和备份，不是完整卸载。管理入口或安装文件损坏时，从另一份可信完整包打开管理入口，再修复或恢复；不要以损坏安装作为恢复来源。

发布说明和素材清单随原解压包保留，不复制到安装目录。原解压包根目录还包含 `START-HERE.md`、[独立 Windows 测试指南](../CLEAN-TEST-GUIDE.md)、环境检查脚本和 `RELEASE-CANDIDATE.json`。此指南链接按解压后的 `skin` 子目录位置解析。
