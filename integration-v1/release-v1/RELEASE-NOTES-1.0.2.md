# 小睦 Codex · 1.0.2

**正式补丁版 · 2026-11-15**

构建编号：`20261115-2228-v1.0.2`。
适配 Microsoft Store Codex **26.1111.2228.0**。

## 这次更新

桌面现在同时提供“小睦 Codex”和“小睦皮肤管理”：一个用于日常启动，一个用于暂停、恢复、修复和更新。开始菜单里的“小睦皮肤管理”继续保留，安装或升级后共有三个专用快捷方式。

本版只让入口更方便，浅绿主题、五秒片头、八秒首页背景以及搜索、菜单和管理器更新流程照旧。

## 怎么升级

已有更新按钮时，在“小睦皮肤管理”中依次点“检查更新”→“下载并更新”。更新后皮肤保持暂停，检测通过后点“启动 / 继续”启用，Codex 窗口和运行中的任务会保留。

旧管理器没有更新按钮时，先下载并完整解压 1.0.2，关闭旧管理窗口，再打开新包的 `skin\manage.vbs`，点“安装 / 修复”。之后就可以在管理窗口里更新。手动备用命令与恢复步骤见 [使用说明](USAGE.md)。

管理窗口显示产品版本 1.0.2。旧版发布和安装包继续保留在 [全部发布](https://github.com/lucifergzsz414/xiaomu-codex-skin/releases) 中。
