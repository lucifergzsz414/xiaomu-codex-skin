# 小睦 Codex · 1.0.4

**正式补丁版 · 2026-11-23**

构建编号：`20261123-4957-v1.0.4`。

适配 Microsoft Store Codex **26.1117.4957.0**。

## 这次更新

这次主要整理了皮肤在切换聊天、设置和菜单时的运行开销：

- 长聊天和侧栏少做重复扫描，已经装饰好的图标不再反复检查。
- 菜单在同一次更新里共用查询结果，皮肤自己的装饰变化也不再触发整轮更新。
- 相同的头像资源只保存一份，五处显示继续使用原图。

同时带上新版 Codex 的搜索、设置和右键菜单适配，以及慢启动时保留片头播放机会的修正。浅绿主题、五秒雨景片头、八秒首页背景和原来的操作方式照旧。

## 怎么升级

已经装好 1.0.3：打开“小睦皮肤管理”，点“检查更新”→“下载并更新”。

从 1.0.2 或更早版本升级：下载并完整解压本版，关闭旧管理窗口，再打开新包的 `skin\manage.vbs`，点“安装 / 修复”。

管理器会校验安装包并备份旧安装；更新后检测通过，再点“启动 / 继续”启用。Codex 窗口和运行中的任务会保留。完整步骤见 [使用说明](USAGE.md)。

旧版发布和安装包继续保留在 [全部发布](https://github.com/lucifergzsz414/xiaomu-codex-skin/releases) 中，上一版为 [1.0.3](https://github.com/lucifergzsz414/xiaomu-codex-skin/releases/tag/v1.0.3)。
