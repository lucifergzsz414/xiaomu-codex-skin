# 小睦 Codex · 1.0.5

浅绿界面、小睦首页、动态背景与五秒雨景片头。适配 Microsoft Store Codex **26.1120.6357.0**，构建编号 **20261127-6357-v1.0.5**。这版修好了右键其他聊天时皮肤暂时消失的问题，也减少了运行中的重复检查，外观与操作方式照旧。

## 开始使用

1. 安装官方 Store Codex，以及默认目录 `C:\Program Files\nodejs` 下的 Node.js 22 或更高版本。在 Codex 外观设置中选择浅色。
2. 完整解压本包，双击 `skin\manage.vbs`，选择“安装 / 修复”。桌面提供“小睦 Codex”和“小睦皮肤管理”，开始菜单也保留管理入口。
3. 首次启用时，保存工作、正常退出 Codex，再从“小睦 Codex”进入。
4. 暂时不用时选择“暂停皮肤”；撤回外观和受管入口时选择“恢复官方外观”。

## 更新皮肤

已经装好 1.0.3 或 1.0.4：在“小睦皮肤管理”里点“检查更新”→“下载并更新”，管理器会完成下载、校验和旧安装备份，更新后重新打开管理窗口。无需登录 GitHub 或安装额外命令行工具。

从 1.0.2 或更早版本升级：关闭旧管理窗口，打开本包的 `skin\manage.vbs`，点“安装 / 修复”，一起换上修正后的更新程序。Codex 可以保持打开，运行中的任务会保留。

更新后皮肤保持暂停，Codex 窗口和运行中的任务会保留。等手头工作结束，正常退出 Codex，再从桌面“小睦 Codex”打开即可用新版。管理器只在点击时检查更新。

旧安装保存在 `backup-repair-*`。旧版发布和安装包也会继续保留。

管理窗口显示产品版本 1.0.5。手动更新备用命令见完整使用说明。
