# 小睦 Codex · 1.0.0-beta.1

这是供受邀测试的 Windows 候选包，编号 `20261031-3384-rc1`。当前实测的官方 Store Codex 版本是 `26.1027.3384.0`；运行目录版本仍为 `1.0.0`。

## 先准备

- 当前用户已安装官方 Microsoft Store Codex。
- Node.js 22 或更高版本位于默认目录 `C:\Program Files\nodejs`。
- 在 Codex 自身的外观设置中选择浅色。

## 安装和使用

1. 将整个压缩包解压，保留这份完整包作为修复来源。
2. 双击 `skin\manage.vbs`，选择“安装 / 修复”。
3. 从桌面“小睦 Codex”或管理窗口的“启动 / 继续”进入。
4. 暂时不用时可“暂停皮肤”；要撤回外观和受管快捷方式时选“恢复官方外观”。

已有旧版时，请先阅读 [使用说明](skin/USAGE.md) 中的升级步骤；完整旧版不会仅因版本标签相同就自动升级。恢复官方外观不会关闭 Codex，也不等于彻底卸载。

## 本轮测试

本机已检查新版自动加载、右键菜单及五个子菜单；当前候选包还经过隔离安装、修复和恢复检查。具体范围见 [候选包记录](RELEASE-CANDIDATE.json)。

另一台电脑或全新 Windows 虚拟机请按 [独立环境测试指南](CLEAN-TEST-GUIDE.md) 操作。本机隔离测试不能代替异机、真实下载提示及系统重启后的验收。两个辅助 EXE 尚未数字签名；出现系统或组织策略阻止时记录提示，不关闭防护或绕过限制。
