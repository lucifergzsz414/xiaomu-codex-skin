# 小睦 Codex · 1.0.3

**正式补丁版 · 2026-11-15**

构建编号：`20261115-2228-v1.0.3`。

适配 Microsoft Store Codex **26.1111.2228.0**。

## 这次更新

- 更新程序从独立工作目录接手，避免安装目录被自身占用，影响旧目录备份和新文件替换。
- 启动失败时，先释放会话占用，再显示中文原因；同时保留一份精简错误记录，方便重试和定位。

相同修正已应用到本机，用户确认关闭 Codex 后重新打开正常。浅绿主题、五秒片头、八秒首页背景、搜索和菜单沿用现有设计。

## 怎么升级

从 1.0.1、1.0.2 或更早版本升级时，这次先下载并完整解压 1.0.3，关闭旧管理窗口，再打开新包的 `skin\manage.vbs`，点“安装 / 修复”。Codex 可以保持打开，运行中的任务会保留。这样会一起换上修正后的更新程序。

装好本版后，后续可以继续在“小睦皮肤管理”里点“检查更新”→“下载并更新”。完成后检测通过，点“启动 / 继续”启用。更新会保留 Codex 窗口和运行中的任务。

管理窗口显示产品版本 1.0.3。完整步骤见 [使用说明](USAGE.md)。旧版发布与安装包继续保留，可在 [全部发布](https://github.com/lucifergzsz414/xiaomu-codex-skin/releases) 中找到；上一版为 [1.0.2](https://github.com/lucifergzsz414/xiaomu-codex-skin/releases/tag/v1.0.2)。
