# 小睦 Codex · 安装与使用

本候选修正片头触发与设置页切换，并保留精简入口和启动等待记录。候选编号见包内 `RELEASE-CANDIDATE.json`。

这是非官方、粉丝制作的 Windows Codex 外观皮肤，与 OpenAI 及角色权利方无隶属或背书关系。素材来源、署名及待补齐的分发依据见原解压包 `skin\ASSET-SOURCES.md`；列出来源不代表已取得全部素材的公开分发授权。

管理窗口、安装清单及安装目录使用运行版本 `1.0.0`，安装目录为 `%LOCALAPPDATA%\XiaomuCodexSkin\1.0.0`。请用候选编号区分同一运行版本下的安装包。发布说明与素材清单随原解压包保留，不复制到安装目录。

## 使用前准备

- 使用当前 Windows 用户安装的 Microsoft Store Codex **26.1103.4239.0**。其他版本需要重新检测。
- Node.js **22 或更高版本**，安装在 `C:\Program Files\nodejs`。本版不从其他 Node 路径自动发现运行时。
- 在 Codex 原生设置中选择**浅色主题**。切到原生深色时，皮肤会退让；不会替你修改原生主题设置。
- 保留可信来源的完整压缩包和解压目录，供后续修复或恢复。两个辅助 EXE 当前未数字签名；文件哈希用于发现损坏，不能替代发行者签名。遇到 Windows、安全软件或组织策略阻止时，记录提示并停止，不关闭系统防护或绕过组织限制。

本候选的检查范围以包内记录为准。独立 Windows 11 普通用户环境的安装、登录、启动和恢复仍待验收。

## 首次安装与启动

1. 完整解压安装包，打开 `skin\manage.vbs`，不要直接从压缩包内运行。
2. 点“安装 / 修复”，确认文件校验通过。桌面提供“小睦 Codex”，开始菜单提供“小睦皮肤管理”。暂停和恢复官方外观在管理窗口里。同名其他程序入口被占用时会报错，不覆盖它。
3. 若管理窗口提示缺少 Node.js 或官方 Store Codex，按提示补齐后点“重新检测”。缺依赖时仍可安装、暂停或恢复，不能启用皮肤；管理窗口不会自动安装依赖。
4. 保存工作后正常退出全部 Codex 窗口，再点“启动 / 继续”或打开桌面“小睦 Codex”。等待管理窗口显示正在运行，并检查真实界面。

若 Codex 已从官方入口打开且没有诊断连接，启动器会等待最多十分钟，等你正常退出后再启动，不会强制关闭。超时后再次打开受管入口即可。暂停皮肤或恢复官方外观可取消等待。

“正在运行”需要会话锁、20 秒内的状态心跳和已加载页面同时成立；旧状态文件不算仍在运行。“兼容”表示组件检测通过，不代表所有页面都已逐项验收。

## 已安装旧候选：手动更新

本版采用手动升级。完整的既有 `1.0.0` 安装重复点击“安装 / 修复”只补齐入口，成功提示不能证明已升级。更新到本测试版时：

1. 保留旧包，在“小睦皮肤管理”点“暂停皮肤”，等皮肤停止，然后关闭所有小睦管理窗口。
2. 解压新的完整候选包，在其 `skin` 文件夹中打开 Windows PowerShell。确认该目录包含 `install.ps1`、`manifest.json` 和 `skin.js`。
3. 在这个目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -SourceRoot . -Repair
```

4. 等待校验和替换完成。旧安装会完整保存在 `%LOCALAPPDATA%\XiaomuCodexSkin\backup-repair-*`，入口恢复记录保留；不要提前删除备份。
5. 从开始菜单打开“小睦皮肤管理”，点“重新检测”确认完整性，再主动点“启动 / 继续”。更新后保持暂停，不会自动启用。

上述执行策略仅作用于这次 PowerShell 进程，不修改系统或用户全局设置；组织强制策略阻止时停止并保留提示。文件被占用等错误会显示目标、备份和暂存目录，先保留现场，再关闭管理窗口重试。不要用已安装目录自身作为更新来源。

更新动作不会关闭 Codex；修复完成后保持暂停，不会自行重启或启用皮肤。需要重新冷启动时，先保存工作，再自行正常退出 Codex。

## 日常入口与管理

桌面“小睦 Codex”与已受管的“Codex”快捷方式使用同一启动器。启动时按目标和精确参数识别并备份已有入口。全新安装只创建小睦的两个专用入口，普通 Codex 快捷方式沿用用户已有的入口。备份和记录位于安装目录的 `entrypoint-backups` 和 `entrypoints.json`。

升级后首次通过小睦入口启动时，旧版自动创建且能校验原样的普通 Codex 快捷方式会先备份再收回。旧版专用快捷方式没有同样的原始校验记录，因此会保留。管理和恢复功能可在开始菜单的“小睦皮肤管理”中找到。

应用搜索结果、协议调用、直接运行官方程序及固定项缓存不一定经过受管入口。任务栏仍启动原入口时，可取消固定后重新固定桌面的 Codex 快捷方式。此功能不修改所有用户目录，也不持续监视系统入口。

在开始菜单打开“小睦皮肤管理”后，可执行以下操作。

| 操作 | 作用 |
| --- | --- |
| 安装 / 修复 | 首次安装；完整的既有安装只补齐入口；损坏时从另一份完整包修复并保留旧目录备份 |
| 启动 / 继续 | 启用皮肤；已有普通 Codex 时等待正常退出 |
| 暂停皮肤 | 撤下当前皮肤并停止辅助会话，保留启动入口；之后主动打开小睦入口可再次启用 |
| 恢复官方外观 | 撤下皮肤，恢复仍符合记录的受管快捷方式；Codex 保持打开 |
| 重新检测 | 校验安装文件并检查当前官方包；状态也会每 30 秒刷新 |

关闭管理窗口不会取消已经发出的安装、暂停或恢复操作。

## 五秒开场与首页背景

本测试版内嵌 **5 秒、1920 × 1080、静音雨景片头**，并保留原有 `hair-rig-v31` 的 **8 秒静音首页循环背景**，无需本地预览服务。本轮保留既有片头与背景素材。

只有从受管入口真正冷启动 Codex 时，片头才有一次播放资格。附着已打开的客户端、切换聊天、恢复皮肤、热更新、重新连接和后续窗口不会重播。可点右上角“跳过”或按 Esc；减少动态、页面隐藏、素材或播放失败及超时都会撤掉片头。片头与真实主页并行，播放时暂停首页背景，结束后恢复。

首页内容区宽度超过 720 像素时播放循环背景，较窄时显示静态封面，并提供暂停按钮。窗口失焦、页面隐藏或系统启用“减少动态效果”时暂停，条件允许后续播；视频无法播放时保留封面。

## Codex 更新与兼容退让

本测试版的支持范围限于上面列出的 Store 版本。每个官方包首次使用时会检查 Store 身份、非开发包状态、包路径、EXE 哈希及界面组件特征；包或组件变化后重新检测。

基础界面、侧栏、工作与设置页、终端与文件面板、搜索与弹窗、右键菜单分别检测。某个模块不匹配时可停用该模块并提示；基础结构或身份检查失败时保留官方界面。未来 Codex 更新可能导致部分退让或完全停用，不能保证自动适配。更新后先重新检测并检查实际界面，有异常时暂停或恢复官方外观。

兼容结果在 `compatibility.json`，运行状态在 `status.json`。本地连接暂不可用时会校验身份后自动重连；身份无法确认时暂停操作或停止，恢复官方外观会取消重连。相关记录不包含聊天正文、输入或登录资料；`session-events.json` 最多保留本次会话的 32 条状态事件。

启动较慢时，`status.json` 在等待期间显示 `workspaceReadiness`。首次加载成功后，`startup-timing.json` 保留首次发现页面、首次就绪和皮肤应用完成的时间，以及最近缺失的界面标记和出现次数。普通工作区和 Dot 是两种可接受的界面，只需有一种就绪。记录只包含固定名称和计时数据，无法代替窗口实际出现时间。

## 修复、回退与恢复

安装损坏时，关闭旧管理窗口，从另一份可信、完整解压包的 `skin\manage.vbs` 打开，再点“安装 / 修复”或“恢复官方外观”。该恢复路径校验完整包，不执行损坏安装中的脚本。修复前会停止皮肤，旧目录保存在 `backup-repair-*`，原入口恢复记录继续保留；修复后保持暂停，需要你主动启用。

管理程序本身打不开时也使用上述完整包入口。备份或入口记录损坏时保留提示，不要自行覆盖。若需要回退到以前保留的可信完整包，先暂停并关闭管理窗口，再按“手动更新”的同一流程以旧包作为来源；该旧包是否支持当前 Codex 仍需重新检测，不能保证回退后可用。

管理窗口的“恢复官方外观”会撤下皮肤并停止辅助会话，Codex 保持打开。后来被你修改或删除的入口不会覆盖；自动创建且仍未改动的普通 Codex 快捷方式会撤销。专用“小睦 Codex”和管理入口保留，之后主动使用小睦入口可再次启用。**恢复不是彻底卸载，本版没有一键完整卸载入口。**

皮肤不修改官方应用包、模型、登录、权限、开机任务或原生主题设置。终端、代码、差异增删行以及错误和警告的语义颜色保留。官方包发现与启动使用 Codex Dream Skin Studio 的固定 MIT 许可库，完整许可见 `LICENSE-upstream.txt`。
