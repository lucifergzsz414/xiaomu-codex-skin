# 小睦 Codex · 1.0.5

**正式补丁版 · 2026-11-27**

构建编号：`20261127-6357-v1.0.5`。

适配 Microsoft Store Codex **26.1120.6357.0**。

## 这次更新

- 适配新版右键菜单，包括新的 HTML 弹出菜单。主菜单、子菜单和原来的操作继续保留。
- 修好右键其他聊天时整页皮肤暂时消失的问题。菜单打开、等待挂载，以及按 Esc 或点击外部取消时，当前页面都保持原样，不改草稿，并保留原有的焦点恢复行为。
- 界面识别改用组件特征，减少菜单因小版本变化而降级的情况；官方进程身份和只读检查继续保留。
- 身份校验集中在首次连接、断线恢复和进程变化时，正常运行少做重复读取与检查。
- 修正取消弹出菜单时的关闭回调；待更新配置先解析再备份，无效内容不再留下多余备份。

浅绿主题、五秒雨景片头、八秒窗边背景与原来的操作方式照旧。

## 怎么升级

已经装好 1.0.3 或 1.0.4：打开“小睦皮肤管理”，点“检查更新”→“下载并更新”。

从 1.0.2 或更早版本升级：下载并完整解压本版，关闭旧管理窗口，再打开新包的 `skin\manage.vbs`，点“安装 / 修复”。

更新时 Codex 和当前任务可以保持打开，旧安装会备份。完成后皮肤保持暂停；等手头工作结束，正常退出 Codex，再从桌面“小睦 Codex”打开即可用新版。完整步骤见 [使用说明](USAGE.md)。

旧版安装包保留在 [全部发布](https://github.com/lucifergzsz414/xiaomu-codex-skin/releases) 中，上一版为 [1.0.4](https://github.com/lucifergzsz414/xiaomu-codex-skin/releases/tag/v1.0.4)。
