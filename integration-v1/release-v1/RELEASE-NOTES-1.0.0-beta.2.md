更新日期：2026-10-31。候选编号：`20261031-3384-rc2`。状态：公开预发布测试版。

## 本版修正

- 安装器与受管快捷方式改用 Unicode `IShellLinkW` / `IPersistFile` 接口，支持中文快捷方式名称和路径。
- 保留快捷方式目标、参数、工作目录、说明、图标与显示方式，以及原有入口识别、备份、用户修改保护和逐字节恢复流程。
- 运行版本和安装目录仍为 `1.0.0`；管理窗口显示该版本属于预期行为，请同时核对候选编号。
- 皮肤内容、首页循环和五秒雨景片头不变；本次打包与发布不会安装、启用或重启当前电脑上的 Codex。

## 安装、升级与恢复

首次使用请完整解压，从根目录 `START-HERE.md` 开始，并按 [USAGE.md](USAGE.md) 操作。独立系统验收指南是原解压包根目录的 `CLEAN-TEST-GUIDE.md`。

已有 beta.1 或其他完整旧安装时，重复点击“安装 / 修复”只补入口，不会自动升级。保留旧包，先暂停皮肤、等待停止并关闭所有小睦管理窗口，然后在新包的 `skin` 文件夹中打开 Windows PowerShell，运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -SourceRoot . -Repair
```

更新保留完整旧目录为 `backup-repair-*`，并保留入口恢复记录。完成后保持暂停，需要重新检测并主动启用；更新和恢复不会关闭 Codex。不要以已安装目录自身作为修复来源。

“恢复官方外观”会撤下皮肤并恢复仍符合记录的受管入口，保留专用小睦入口和备份；它不是彻底卸载。本版没有自动升级、一键完整卸载或数字签名。

安装包名称：`xiaomu-codex-skin-1.0.0-beta.2-20261031-3384-rc2.zip`。请使用同名 `.sha256` 文件核对；文件哈希用于发现损坏，不替代发行者数字签名。
