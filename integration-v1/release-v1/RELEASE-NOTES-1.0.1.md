## 怎么升级

已有更新按钮时，在“小睦皮肤管理”中依次点“检查更新”→“下载并更新”。

旧管理器没有更新按钮时，先下载并完整解压 1.0.1，关闭旧管理窗口，再打开新包的 `skin\manage.vbs`，点“安装 / 修复”。之后就可以在管理窗口里更新。手动备用命令与恢复步骤见 [使用说明](USAGE.md)。

安装目录仍为 `%LOCALAPPDATA%\XiaomuCodexSkin\1.0.0`，这是目录布局版本；管理窗口显示产品版本 1.0.1。日常入口为桌面“小睦 Codex”和开始菜单“小睦皮肤管理”。旧版发布仍保留在 [全部发布](https://github.com/lucifergzsz414/xiaomu-codex-skin/releases) 中。
