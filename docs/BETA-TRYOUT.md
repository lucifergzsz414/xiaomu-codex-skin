# 小睦皮肤 Beta 试用说明

当前试用版为 **1.0.0-beta.2**，候选编号 **20261031-3384-rc2**。欢迎按平时的使用方式体验，有问题时告诉我们发生了什么。它仍是测试版，已验证范围见[验收记录](../qa/RELEASE-READINESS.md)。

## 开始之前

- 本候选支持和既有实机验证的客户端为 Microsoft Store Codex **26.1027.3384.0**；其他版本也可以反馈问题，请写明实际版本。
- 需要 **Node.js 22 或以上版本，使用默认安装位置**，并在 Codex 原生设置中选择**浅色主题**。详细要求见[使用说明](../integration-v1/release-v1/USAGE.md#使用前准备)。
- 从 [Beta.2 Release](https://github.com/lucifergzsz414/xiaomu-codex-skin/releases/tag/v1.0.0-beta.2) 下载完整安装包，解压后保留原包与解压目录。源码压缩包不能代替安装包。
- 首次安装、旧版升级、暂停和恢复都按[现有步骤](../README.md#安装与恢复)操作；完整旧安装重复点击“安装 / 修复”不代表已经升级，请另看[手动升级说明](../README.md#已安装旧候选时升级)。

## 日常顺手看这几处

| 场景 | 可以留意什么 |
| --- | --- |
| 首页与聊天 | 浅绿是否加载，正文是否清楚，窗口变窄后是否拥挤或遮挡 |
| 平时会用的控件 | 菜单、设置或图片预览有没有看不清、点不到、重叠的地方 |
| 暂停与恢复 | 管理窗口的提示是否明确，皮肤是否撤下，Codex 是否保持打开 |

不需要专门搭虚拟机、制造故障或发送测试消息，也不用中断正在进行的工作。首次启动需要正常退出既有窗口时，先等当前任务结束。

如果正好要重新打开 Codex，可以留意从小睦入口启动后的自动加载与五秒片头。系统重启后的观察也等你原本需要重启时再做；未尝试的场景直接写“未测试”。这些试用建议不代表相关流程已经完成正式验收。

## 遇到问题

先记录你做了什么、实际出现什么、原本期望什么，再通过[问题反馈表](https://github.com/lucifergzsz414/xiaomu-codex-skin/issues/new?template=skin-problem.yml)提交。请附上候选版本、Store Codex 版本、Windows 和 Node.js 版本；不知道的项目写“不确定”即可。

错误提示和截图均可选，先遮住私人内容。不要上传聊天正文、登录资料、密钥、令牌、私人路径或整个用户目录。遇到系统或安全软件阻止运行，保留提示并停止，不必关闭防护。

需要退回官方外观时，按[恢复说明](../integration-v1/release-v1/USAGE.md#修复回退与恢复)操作。完整原包可用于后续修复，请保留；恢复外观不等于彻底卸载。
