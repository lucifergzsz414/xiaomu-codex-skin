# 日常使用与反馈

当前正式版为 **1.0.2**。[下载安装包](https://github.com/lucifergzsz414/xiaomu-codex-skin/releases/download/v1.0.2/xiaomu-codex-skin-20261115-2228-v1.0.2.zip) · [发布说明](https://github.com/lucifergzsz414/xiaomu-codex-skin/releases/tag/v1.0.2) · [设计说明](DESIGN.md) · [返回首页](../README.md)

## 装好并跑起来

开始前先确认三件事：电脑上装的是 Microsoft Store 版 Codex **26.1111.2228.0**，默认目录 `C:\Program Files\nodejs` 下有 **Node.js 22+**，并且已经在 Codex 原生设置里把外观调成了**浅色**。

把下载好的压缩包完整解压，保留原压缩包和解压目录。双击里面的 `skin\manage.vbs`，点“安装 / 修复”。接着保存工作并正常退出 Codex，再从桌面「小睦 Codex」打开。桌面还提供「小睦皮肤管理」，开始菜单也保留同名管理入口。

## 更新到新版

管理窗口里点“检查更新”，看到新版本后点“下载并更新”。无需登录 GitHub，也不用安装额外命令行工具；管理器会下载、校验并备份旧安装，更新后重新打开窗口。

这时皮肤会保持暂停，等检测通过后点“启动 / 继续”启用。更新会保留 Codex 窗口和运行中的任务。管理器只在点击时查新版本，不会在日常启动时联网检查。

如果旧管理器里还没有更新按钮，这次先下载并解压 1.0.2，关闭旧管理窗口，再双击新包的 `skin\manage.vbs`，点“安装 / 修复”。完成后就换上了带更新按钮的管理器，以后直接在里面升级。

管理窗口会显示产品版本 1.0.2。这次主要是让桌面启动和管理更方便，原有外观、片头、背景与更新流程照旧。

## 平时怎么用

装好之后，打字、看代码、改文件都和原来一样，主要多了这几处细节：

- **开屏片头与窗边背景**：每次从桌面「小睦 Codex」正常启动时，会播放一次五秒静音雨景片头。点击或打字不会误触打断；想直接进工作区，点“跳过”或按 Esc。切换页面或者网络重连不会重播。首页的八秒静音窗边背景可以手动暂停，窗口切到后台、拉窄或者系统开了“减少动态效果”时也会自动停下。
- **搜索与右键菜单**：在搜索框底部切换文件或文本搜索，再用目录菜单选项目。同一个聊天里再次打开搜索，会记住所选目录。右键主菜单、子菜单和快捷键保留原本的用法。
- **暂停与恢复官方外观**：临时想看原版界面，在「小睦皮肤管理」点“暂停皮肤”。点“恢复官方外观”还会恢复受管入口，Codex 窗口、专用小睦入口和备份都会保留。

包里的 `START-HERE.md` 和 `skin\USAGE.md` 有完整的安装、手动更新与恢复步骤；独立电脑测试可看 `CLEAN-TEST-GUIDE.md`。本次验证记录集中在 [1.0.2 更新说明](../integration-v1/release-v1/RELEASE-NOTES-1.0.2.md)。

## 遇到问题怎么反馈

如果发现颜色不对、按钮错位、启动或更新报错，可以通过 [反馈表](https://github.com/lucifergzsz414/xiaomu-codex-skin/issues/new?template=skin-problem.yml) 告诉我：

- 皮肤、Microsoft Store Codex、Windows 和 Node.js 的版本号；拿不准的直接填“不确定”。
- 刚才做了哪几步，实际发生了什么；更新问题也请写下更新前后的版本和管理窗口提示。
- 方便的话附一张截图或报错文字，传图前遮住项目名、私人路径和代码。

问题影响手头工作时，可先在「小睦皮肤管理」里点“恢复官方外观”，把原压缩包和 `backup-repair-*` 备份留好，方便后面修复。
