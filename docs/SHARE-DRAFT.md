# 小睦皮肤分享文案

想推荐给同好的话，可以从下面这段介绍改起。

## 可复制正文

给平时在用 Windows 版 Codex 的同好分享一个自己整理的非官方外观主题：**小睦 Codex Skin（1.0.0 正式版）**。

整体是偏柔和的浅绿和奶白配色，把 Q 版小睦放在了首页卡片、侧栏欢迎区和签名里，配了一段八秒静音循环的窗边背景，每次正常启动还会播一次五秒静音雨景片头（点击或打字不会误触掐断，赶时间可以点“跳过”或按 Esc）。输入、右键菜单和快捷键还是熟悉的用法，文件差异也保留了清楚的红绿。搜索文件或文本时，会按当前聊天记住选过的项目目录。

平时从桌面的「小睦 Codex」启动就行；想切回原版界面，在开始菜单「小睦皮肤管理」里随时可以暂停或恢复官方外观，不会关掉正在用的窗口。

当前适配环境：
- Windows x64 + Microsoft Store Codex **26.1111.2228.0**
- 默认路径 `C:\Program Files\nodejs` 下安装的 **Node.js 22+**
- Codex 原生设置选**浅色主题**

如果正好在这个环境里工作、想把小睦放进日常界面，可以从下面拿到安装包和说明。用的时候要是碰到颜色、布局或启动上的小状况，欢迎顺手提个反馈（记得把截图里的私人代码和目录遮一下）：

- 1.0.0 发布说明：https://github.com/lucifergzsz414/xiaomu-codex-skin/releases/tag/v1.0.0
- 仓库主页与设计/使用说明：https://github.com/lucifergzsz414/xiaomu-codex-skin
