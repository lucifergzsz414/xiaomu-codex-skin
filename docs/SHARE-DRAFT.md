# 小睦皮肤分享文案

想推荐给同好的话，可以从下面这段介绍改起。

## 可复制正文

给平时在用 Windows 版 Codex 的同好分享一个自己整理的非官方外观主题：**小睦 Codex Skin（1.0.1 正式版）**。

整体是柔和的浅绿和奶白配色，把 Q 版小睦放在首页卡片、侧栏欢迎区和签名里，配了一段八秒静音循环的窗边背景，每次正常启动还会播一次五秒静音雨景片头，赶时间可以点“跳过”或按 Esc。输入、右键菜单和快捷键还是熟悉的用法，文件差异也保留清楚的红绿。搜索文件或文本时，会按当前聊天记住选过的项目目录。

这次 1.0.1 加上了管理器更新：在「小睦皮肤管理」里点“检查更新”，有新版就点“下载并更新”。下载、校验和旧版备份会自动完成，不用登录 GitHub。更新后管理窗口会重新打开，皮肤保持暂停，再点“启动 / 继续”就能启用，Codex 里的任务会保留。只有点按钮时才查更新，平时启动照常。

平时从桌面「小睦 Codex」启动；想切回原版界面，在开始菜单「小睦皮肤管理」里暂停或恢复即可。旧管理器没有更新按钮的朋友，这次下载新包、关闭旧管理窗口，再打开新包的 `skin\manage.vbs` 点“安装 / 修复”，以后就在管理窗口里升级。

当前适配环境：

- Windows x64 + Microsoft Store Codex **26.1111.2228.0**
- 默认路径 `C:\Program Files\nodejs` 下安装的 **Node.js 22+**
- Codex 原生设置选**浅色主题**
