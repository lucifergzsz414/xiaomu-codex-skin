## 可复制介绍

小睦 Codex Skin 是一个非官方的 Windows Codex 外观主题：浅绿与奶白、Q 版小睦、八秒静音窗边背景，还有五秒开场片头。现在提供 1.0.0-beta.2 小范围试用，想把小睦放进工作界面的朋友可以看看。

这版适配 Microsoft Store Codex 26.1027.3384.0，需要默认位置安装的 Node.js 22+，并在 Codex 中选择原生浅色。其他版本需重新检测。安装、暂停和恢复步骤都在仓库里；遇到颜色、布局或启动问题，可以附版本和复现步骤反馈，截图记得遮住私人内容。日常使用时顺手留意即可，没测过的场景写“未测试”就好。
